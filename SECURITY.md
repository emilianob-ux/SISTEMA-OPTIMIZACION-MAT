# Security policy / Política de seguridad

## Reporting / Reporte

**English:** If you believe you’ve found a security vulnerability in this repository (e.g. unsafe deserialization, credential leakage in tooling), please **do not** open a public issue. Report it privately so we can fix it responsibly.

**Español:** Si creés haber encontrado una vulnerabilidad de seguridad en este repositorio, **no** abras un issue público. Reportalo de forma privada.

### How to report / Cómo reportar

1. Use **[GitHub Private vulnerability reporting](https://docs.github.com/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)** for this repository if it is enabled by maintainers.  
2. If private reporting is not enabled: contact the maintainer via their GitHub profile: https://github.com/emilianob-ux

Include: affected component or script, steps to reproduce, impact estimate. Avoid attaching production databases or secrets.

---

## Scope / Alcance

This policy applies to code **in this repository** (Python tooling, CI workflows). It does **not** cover exchange APIs, your trading accounts, or third-party data providers.
