# Launch Day Checklist

## Before posting

- [ ] Release v0.3.0 is public
- [ ] README and README.en are up to date
- [ ] Quickstart commands tested on clean env
- [ ] One short demo clip captured (30-60s)
- [ ] Links prepared (repo, release, discussion)

## Publish sequence

1. LinkedIn post (ES)
2. X/Bluesky post (EN)
3. Reddit post in 1-2 relevant communities
4. Show HN submission
5. DEV/Hashnode technical post

## During first 24h

- [ ] Reply to every question/comment
- [ ] Convert vague comments into actionable issues
- [ ] Pin best feedback in discussion
- [ ] Capture traffic and star deltas

## End of day recap

- [ ] Publish mini update in Discussion thread
- [ ] Record what channels worked best
- [ ] Prepare next day post from data
