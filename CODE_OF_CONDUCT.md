# Contributor Covenant Code of Conduct / Código de conducta

## Our pledge / Nuestro compromiso

We foster an open, respectful environment for everyone (language, background, experience level).

Promovemos un entorno abierto y respetuoso para todas las personas.

## Our standards / Estándares

Examples of behavior that contributes:

- Using welcoming and inclusive language  
- Accepting constructive criticism gracefully  
- Focusing on what is best for the community  

Unacceptable: harassment, trolling, publishing others’ private information, or other conduct inappropriate in a professional setting.

## Enforcement / Aplicación

Maintainers may remove, edit, or reject contributions if this code is violated.

Report incidents to project maintainers via the contact in **SECURITY.md** or repository discussions as appropriate.
